# Викторины РППС В ДОО — каталог с вашими играми

В каталог добавлены два предоставленных HTML-файла:
- `public/quizzes/znatok-pdd.html` — «Дорожные знатоки» / «Знаток ПДД»
- `public/quizzes/znatok-multfilmov.html` — «Знаток советских мультфильмов»

Оригинальные игры сохранены как отдельные HTML-файлы. Каталог открывает их во встроенном игровом окне; кнопка «Все викторины» возвращает в каталог.

## Публикация
1. Распакуйте архив.
2. Загрузите все файлы и папки в GitHub-репозиторий. Не переименовывайте папку `public/quizzes`.
3. Подключите репозиторий к статическому хостингу, который поддерживает Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Укажите полученный HTTPS-адрес в настройках размещения VK Mini App.

## Локальная проверка
Требуется Node.js LTS: https://nodejs.org/
```bash
npm install
npm run dev
```
Сборка:
```bash
npm run build
```

## Примечание
Файлы викторин крупные, потому что иллюстрации и шаблоны сертификатов встроены прямо в HTML. Проверьте лимиты выбранного хостинга перед публикацией. Этот комплект добавляет ваши игры в каталог, но не подключает базу данных, авторизацию VK или защищённую панель администратора.
